GRAVEYARD ORBIT MAPS — COW ABDUCTION (0.1.0)
===========================================

WHAT THIS IS
  An original custom contract/map for Graveyard Orbit: a UFO beaming up a cow,
  built from 50,221 hex cells. This package includes BepInEx, a small loader
  plugin and the map; no compiler or separate mod loader is needed.

REQUIREMENTS
  - Windows 10/11, or Linux / Steam Deck (Proton)
  - Graveyard Orbit installed through Steam (AppID 4654120)

INSTALL (SAME ON WINDOWS AND LINUX)
  1. Close Graveyard Orbit.
  2. In Steam, right-click Graveyard Orbit > Manage > Browse local files.
     That opens the game folder (the one containing GraveyardOrbit.exe).
  3. Download the release zip:
       https://github.com/Grokent/graveyard_orbit_maps/releases/latest/download/GraveyardOrbit-UfoCow-0.1.0.zip
  4. Extract EVERYTHING from this zip into the game folder that opened in
     step 2. It only adds files; no original game file is replaced or
     modified:
       winhttp.dll
       doorstop_config.ini
       .doorstop_version
       changelog.txt
       BepInEx/...
  5. Linux / Steam Deck (Proton) ONLY: add this launch option once
     (game > Properties > Launch Options):
       WINEDLLOVERRIDES="winhttp=n,b" %command%
     Windows needs no launch options.
  6. Launch the game through Steam.

PLAY
  New Game > COW ABDUCTION (first in the contract list).
  - Four gold-capped entrances at the leg bottoms lead into a 3-wide black
    maze. The south is gold/blue and easy; the north is purple/pink and hard.
  - 24 hidden rooms, 20 artifacts (power-up rolls), 120 glyphs (beacons for
    2 players x 20 relics), 64 salvage crates, 298 mod-material veins.

UNINSTALL
  Delete BepInEx/plugins/GraveyardOrbit.UfoCow/
  Remove winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and
  BepInEx/ only if you do not use any other BepInEx mod.
