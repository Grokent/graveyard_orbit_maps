# AGENTS.md — Graveyard Orbit Maps

## Purpose

This project generates **COW ABDUCTION** (`ufo_cow`), an original custom
contract/map for **Graveyard Orbit** (Steam AppID 4654120): a saucer/dome UFO
tractor-beaming a cow, built from ~50,000 hex cells.

A second contract, **BATTLE MOON** (`battle_moon`), is a 59,819-cell
planet-killer battlestation seen in 3/4 view from below-right. Layer 1 is
structural — black grout between every hull panel, open panel bays, and a wide
equatorial trench — so there is no winding labyrinth. The superlaser dish sits
north of the equator and left of centre, and the hull is divided into eight
panelled sectors. It has its own generator and validator; see
`docs/BATTLE_MOON.md`. The rest of this file (data model, layers, rooms, bands,
loader rules) applies to both maps.

The map is an original creation. **No Graveyard Orbit game code or game asset
files are stored here.** The map is data in the same JSON shape the game itself
parses, generated by `generate_map.py`. Graveyard Orbit and all related content
belong to Anchorhead Games; this is an unofficial fan project.

## The game's contract model

A contract is a `StructureDef` ScriptableObject. The fields that matter for a
map:

| Field | Meaning |
|---|---|
| `id` | stable string key (`ufo_cow`) |
| `displayName` / `description` | UI text |
| `cells` | `TextAsset` containing the map JSON below |
| `cellCount` | number of cells (must match `count`) |
| `sealedLayers` | if true, a layer is locked until the previous band is fully cleared |
| `startingMoney` | money granted when the contract starts |
| `bands` | one `BandDef` per layer (1–5) |
| `artifactCells` | explicit `Vector2Int[]` artifact spawn cells |
| `glyphCount` | number of random anomaly glyph pickups |
| `greenCount` | total salvage crates; `roomGreen` cells count toward it |

The map file itself is the `MegastructureData` JSON:

```json
{
  "source": "ufo_cow",
  "count": 50221,
  "q": [...], "r": [...],
  "alt": [...], "layer": [...],
  "bounds": { "q": [qmin, qmax], "r": [rmin, rmax] },
  "rooms":      { "q": [...], "r": [...], "id": [...] },
  "roomGreen":  { "q": [...], "r": [...] }
}
```

- `q`, `r`, `alt`, `layer` are parallel arrays of length `count`.
- `bounds` is mandatory (the parser reads it directly).
- `rooms` / `roomGreen` are optional objects, but if present all their arrays
  must be the same length and every cell must exist in `q`/`r`.
- Cell order does not matter technically; this project sorts by `(r, q)`.

## Hex geometry

Axial coordinates `(q, r)`. With `hexSize = 1` the game maps them to world space:

```
world.x = 1.71875 * (q + r * 0.5)
world.z = -1.5 * r
```

Hex distance:

```
d = (|dq| + |dr| + |dq + dr|) / 2
```

The planet/launch side is at **maximum r** (negative world z). The map's
`rMax` also drives the planet distance and camera extent, so keep the body
inside the `r` bounds and leave the entrance on that side. The ship enters from
the planet and flies toward lower `r`.

The six axial neighbours are:

```
(1,0) (1,-1) (0,-1) (-1,0) (-1,1) (0,1)
```

## Layers, colours, HP and “tiers”

Layers are **1–5** and are the map's tier system. `layer` is the only per-cell
tier value in the map JSON. The game maps it to a colour and a damage family:

| Layer | Colour | `ColourRules` HP (unsealed) | Weapon family that matches | Notes |
|---|---|---:|---|---|
| 1 | Black | **15** | any (black ignores colour penalty) | lowest tier; all maze tunnels |
| 2 | Blue | **60** | sweeper | cow body |
| 3 | Pink | **160** | ballistics / drill | toughest; main beam/wall mass |
| 4 | Gold | **40** | laser | outer rim/veins |
| 5 | Purple | **90** | pulse | wall shell around tunnels |

Damage colour rules (`ColourMath`):

- tile is **Black** (layer 1) or no attacker colour → **1.0×** damage;
- attacker colour matches the tile colour → **1.0×**;
- otherwise → **0.25×** (off-colour penalty).

So layer 1 is *the* beginner material: 15 HP and no colour penalty, while the
pink/purple shell around it soaks damage unless the player brings the matching
weapon family.

Two different HP sources exist in the game and are easy to confuse:

- `ColourRules.HpOfLayer` (table above) is used when a layer is **not sealed**.
- `BandDef.hpSealed` is used **only** when `StructureDef.sealedLayers == true`
  and the band is still sealed (previous layer not fully collected).

The per-material `base_hp` values in `game_data_legacy.json` (substrate 15/25/
40/60/85) are the data-file defaults; the live `TileField` path above wins for
substrate cells. This map sets `sealedLayers = false`, so the `ColourRules` HP
column is the one that applies.

### Materials and the `alt` column

`alt` encodes authored special tiles and enemy placements. 0 means “none”
(the layer's substrate). The authoritative codes:

| `alt` | Tile | Colour | `minLaserTier` | Resource value | Role |
|---:|---|---|---:|---:|---|
| 0 | substrate | layer colour | 0 | 1 | normal cell |
| 3 | explosive | — | 0 | 0 | authored enemy |
| 4 | lightning | — | 0 | 2 | authored enemy |
| 5 | void | — | 0 | 1 | authored enemy |
| 15 | swarm | — | 0 | 1 | authored enemy |
| 6 | `special_1` | gold | 0 | 2 | resource vein |
| 7 | `special_2` | red | 0 | 3 | resource vein |
| 8 | `special_3` | blue | **1** | 4 | resource vein |
| 9 | `meta_1` | green | **1** | 3 | meta material |
| 10 | `meta_2` | artifact | **1** | 1 | artifact pickup |
| 11–14 | substrate layer markers | — | — | — | layer look (not used here) |

“Tier” in the material sense is `minLaserTier`: the player's laser tier must be
at least this value to **collect** the material (`field.CanMineMaterial`), even
though the tile can still be destroyed. `special_3`, `meta_1` and artifacts are
tier-1; the rest are tier-0.

This map authors 298 specials via `alt` (~110/90/59/40 cells for
`special_1/2/3` and `meta_1`) as **clustered veins**, not single scattered
cells. Band `special*` counts are all **0**, so there is no procedural material
confetti; bands only seed enemies.

## Reference distributions and pickup frequencies (analysis)

The shipped `structure_005.json` map and the co-op mod's runtime-merged 50k
reference were analysed for layer ratios. A base 25k contract was also
inspected through the game's own runtime logs. Only aggregate statistics are
quoted; no map data is copied into this project.

| Reference | Cells | L1 | L2 | L3 | L4 | L5 |
|---|---:|---:|---:|---:|---:|---:|
| `structure_005` (streaming asset) | 10,262 | 43.4% | 31.7% | 16.3% | 6.2% | 2.4% |
| merged 50k (co-op reference) | 50,499 | 56.0% | 12.0% | 7.7% | 11.0% | 13.4% |
| **COW ABDUCTION** | **50,221** | **28.2%** | **10.6%** | **16.1%** | **21.2%** | **23.9%** |

The base 25k contract logs give the pickup budget used here:

| Pickup | What it is in code | Base 25k | This 50k map |
|---|---|---:|---:|
| Artifacts (`meta_2`) | one **power-up roll** each (`Boosters.AddFoundRoll`) | 12 | **20** |
| Glyphs | **beacon**; 3 beacons = 1 relic key, 20 relics | 58 | **120** |
| Authored specials (`alt` 6–9) | mod-material / colour-shard veins | 166 | **298** |
| Salvage crates (`roomGreen`) | money crates | 40 | **64** |
| Hidden rooms | breach chambers | 20 | **24** |

Design rules derived from that:

- **Beacons:** 20 relics × 3 beacons = 60 per player. 120 glyphs means two
  players can each unlock all 20 relics even if beacons are shared, and it
  matches the reference frequency (58 per 25k ≈ 116 per 50k).
- **Artifacts:** the reference rate is ~12 per 25k (0.048%). 20 here gives one
  power-up roll for most hidden rooms without flooding the map.
- **Specials:** the reference authors ~166 per 25k (0.66%); 298 here (0.59%)
  sits in the same band, but they are clustered and tier-placed instead of
  being sprinkled one-per-cell.
- **Layer mix:** COW ABDUCTION deliberately uses far less L1 than the merged
  reference (28% vs 56%) so the black cells form a readable maze rather than
  the whole field, and spends the budget on the purple/pink northern shell and
  gold/blue southern approach.

## Bands

`BandDef` (one per layer) controls procedural seeding and sealing:

```csharp
layer, outerFrac, hpSealed, unsealedLook,
special1, special2, special3, meta1,
explosive, lightning, voidTiles, swarm
```

- `SeedSpecials` picks `special1..meta1` cells **per layer**, with 3-cell
  spacing, from cells with no authored material.
- `EnemyManager.SeedPerLevel` picks `explosive`/`lightning`/`voidTiles`/`swarm`
  dormant enemies **per layer**, also 3-cell spacing. They are revealed when a
  nearby tile is destroyed (`EnemyManager.OnTileDestroyed`) or by reveal waves.
- `sealedLayers = true` seals layer *n* until every cell in layer *n-1* is dead,
  and if the band has a `hpSealed` value, that becomes the sealed HP. This map
  keeps `sealedLayers = false` so beginners can break into pink/purple whenever
  they like. The band `hpSealed` values are documented but inactive here.
- `outerFrac`/`unsealedLook` are presentation knobs; defaults are fine.

## Hidden rooms, green shards, glyphs, artifacts

- **Hidden rooms**: `rooms.q/r/id`. Each `id` is a chamber of 7–19 cells embedded
  in mass. When a player destroys a tile adjacent to a room, the room "breaches"
  and its cells open. Rooms are sealed by ≥4 cells of mass from the maze.
- **Green shards / salvage crates**: `roomGreen.q/r`. `PaintGreenShards` paints
  these first, then (only for campaign contracts) fills up to `greenCount` with
  random candidates. This map sets `greenCount = 64` equal to the authored count.
- **Glyphs**: `glyphCount` random anomaly glyph pickups; **120** here (enough
  for two players to open all 20 relic slots: 2 × 20 × 3 = 120 beacons).
- **Artifacts**: explicit `artifactCells` in the contract (not in the map JSON).
  **20** cells, each inside a hidden room. They become `meta_2` pickups and
  grant a power-up roll each.
- Rooms, green and artifacts are excluded from procedural enemies/materials by
  the game's candidate filtering.

## This map's design

`ufo_cow`, **COW ABDUCTION**, scale 1.096, seed 0xC0FFEE:

- **50,221 cells**, bounds `q[-197,173] r[-164,168]`.
- Silhouette: saucer hull + rim + dome at the top, a widening tractor beam, and
  a cow (body, head, ears, horns, udder, four legs, tail + tuft) at the planet
  side.
- **Labyrinth**: braided maze on a 12-cell grid (spanning tree + 18% loops +
  black plazas at some southern junctions), carved as a dilation of the
  centreline so every corridor is **3 cells wide**. All layer-1 cells form one
  connected network.
- **Four entrances** at the four leg bottoms, each sealed by a **2-cell gold
  (L4) plug** across the full 3-wide mouth; the third cell inward is already
  black. The tail is a connected black corridor as well. The player enters from
  the planet side; the southern boundary is gold, not purple/pink/blue.
- **South-to-north gradient**:
  - South third: gold/black/blue, with tunnel walls **77% L4 gold / 20% L2
    blue**; very little pink or purple.
  - Middle third: black maze, blue/gold walls, some purple.
  - North third: purple/pink shell (tunnel walls **100% L3/L5**).
  - Mean mass HP: **58 south → 82 mid → 113 north** (measured with
    `ColourRules` HP).
- **Hidden rooms**: 24 chambers of 7–18 cells, at least 4 cells from any tunnel.
  Six southern rooms are deliberately wrapped in a 2–3 cell pink/purple shell
  even though the surrounding gradient is gold/blue.
- **Pickups**: 64 salvage crates, 20 artifacts (power-up rolls), 120 glyphs
  (beacons), and 298 authored specials in tier-placed clusters (gold lower,
  red mid, blue/green north). Band material counts are zero; bands only seed
  enemies.

Regenerating with the same scale/seed reproduces the map exactly. Changing
`--scale` trades silhouette size against cell count (aim for 49k–52k).

## Best practices for future map sessions

See `docs/MAP_BEST_PRACTICES.md` for the full workflow and the traps that cost
time. The short version:

- Measure a reference map's layer mix, room sizes and pickup counts before
  designing; use ordered `zip(q, r)` (never zip a `set` with the parallel
  arrays).
- Keep the generator deterministic; tune `MAZE_SPACING`, plazas and loops for
  the black share. COW ABDUCTION uses spacing 12 + 26% plazas for 28.2% L1.
- Carve entrances with BFS through `cells`, not straight lines, and seal the
  full 3-wide mouth with a 2-cell gold cap. Straight lines skip cells and
  disconnect; centreline-only caps leave isolated black side-lobes.
- Assign layers with a south→north gradient and coherent (5-cell block) patches,
  not per-cell noise. South = gold/blue walls, north = purple/pink.
- Author specials as clustered veins and set band `special*` counts to 0;
  procedural materials are what make maps look like confetti and can block
  green cells (`SeedSpecials` runs before `PaintGreenShards`).
- Budget pickups from the reference rates: artifacts = power-up rolls, glyphs =
  beacons (3 per key, 20 keys/player), green = money crates. Use 120 glyphs for
  a 2-player relic budget.
- Run `validate_map.py` every regeneration; it hard-fails on connectivity,
  entrance caps, gradient, 25–35% black, room/pickup budgets.
- Deploy, restart, and start a **new** contract; continuing an old save keeps
  its destroyed cells. Never `Resources.Load` from plugin `Awake`.

## Validation rules (`validate_map.py`)

1. `q/r/alt/layer` all equal `count`; no duplicate cells.
2. Count within 49,000–52,000 and equal to `contract.cellCount`.
3. Layers 1–5 only; `alt` only 0/6/7/8/9 in this map.
4. `bounds` equals the real min/max of `q`/`r`.
5. Layer-1 share is **25–35%** (currently 28.2%).
6. At least **4 entrances**, each on the boundary, layer 4 (gold), with a
   reachable layer-1 tunnel behind the plug.
7. The whole layer-1 network is one connected component; 3-wide erosion/
   regrowth coverage ≥95%.
8. No wall cell is layer 1; the south third is ≥60% L2/L4 and the north third
   is ≥60% L3/L5; south mean mass HP is below north.
9. Rooms: 20+ chambers, arrays consistent, cells exist, 7–19 cells, ≥3 cells
   from tunnels, no room cell is L1.
10. At least 16 artifacts, all inside rooms; 56+ green shards; `greenCount`
    matches the authored green cells.
11. `glyphCount` ≥ 120 (2 players × 20 relics × 3 beacons).
12. Authored specials 250–340, clustered, not in tunnels; bands have zero
    procedural special counts; gold specials sit south of blue/green.

## Loading it as a contract

The game's live `StructureCatalog` is a ScriptableObject asset, so adding a
contract at runtime is the same pattern used by the co-op mod: create a
`StructureDef`, set its fields, put the map JSON into `def.cells = new
TextAsset(json)`, append to `catalog.campaign`/`ladder`, and insert into the
catalog cache. The included `loader/` plugin does exactly this: it reads the two JSON files
from its own plugin folder, injects the contract, and logs
`[ufocow] injected 'ufo_cow' (50221 cells, 5 bands)`. See `docs/INJECTION.md`
for the same pattern in compact C# and the gotchas.

Key values from `contracts/ufo_cow.contract.json`: `sealedLayers = false`,
`startingMoney = 4000`, 5 bands, **20 artifact cells**, **120 glyphs**,
**64 green shards**. `cellCount` must match the map exactly.

## Gotchas

- The map JSON's `bounds` is required; the parser indexes it directly.
- Keep `count` and every array length identical. A mismatch breaks the field.
- Do not put layer 1 outside the maze: layer 1 is the “easy” signal, and the
  walls must be L3/L5.
- Keep the bottom (planet side) entrance open. The map is approached from
  maximum `r`.
- `roomGreen` counts toward `greenCount`; this map sets `greenCount = 64`,
  exactly the authored count.
- Keep band `special1..meta1` at zero: procedural material seeding is disabled
  on purpose so the authored, tier-placed veins stay readable. Enemies still
  seed from the band behavior counts.
- Do not add `meta_2`/alt 10 to the map; artifacts come from `artifactCells`.
- The loader must **not** call `StructureCatalog.I`/`Resources.Load` from
  plugin `Awake`; BepInEx loads plugins before Unity resources are ready and
  the process crashes. The loader injects from a `MainMenuController.BuildUI`
  postfix instead.
- The project is pure data generation: no game DLLs, no decompiled code, no
  redistributed Anchorhead assets.
- Never commit the installed game folder, logs, saves or decompiled output.
